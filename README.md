# OSS Watch Desk — Operating Repository

This repository is the editorial source of truth for the open-source watch
series. It is maintained by the research desk and read by the publishing
pipeline.

Layout:
- `catalogue/source_items.json` — the current watch-list. Each entry pairs a
  published episode with the repository identifier that the next companion post
  will cite. This file is generated by the desk and must not be rewritten by
  hand.
- `policy/citation_policy.md` — the editorial policy every register must follow.
- `reviews/` — published registers live here. Each cycle publishes exactly one
  register named `citation_audit.csv`.

A hold list is published alongside every register for citations that cannot go
out as written (`reviews/hold_list.csv`).
